# Product Overview

Coreysmaller.com is a personal portfolio website showcasing creative work across multiple media types.

## Core Features

- **Blog System**: Rich text blog posts with markdown migration support
- **Music Portfolio**: Original music tracks with audio playback
- **Video Gallery**: YouTube video integration and management
- **Audio Content**: SoundCloud audio embedding
- **Admin Panel**: Secure content management interface with JWT authentication

## Target Users

- Primary: Site owner (content creator/musician)
- Secondary: Visitors consuming blog posts, music, videos, and audio content

## Key Characteristics

- SEO optimized for content discovery
- Responsive design (mobile, tablet, desktop)
- Performance optimized with caching and compression
- Security-focused with helmet, rate limiting, and input validation
